# Case studies — internal drafts

These files are excluded from the public build. They are briefs for real projects, not completed client case studies. No numbers, screenshots, client identities or results should be invented.

Use the three draft outlines to collect evidence. Before publishing, confirm the project is real, obtain permission for the identity/data/screenshots, define the baseline and comparison period, distinguish channel metrics from business outcomes, and record attribution limits. For anonymous work use a factual descriptor and state that the client name is withheld by request.

When at least one approved case is ready, implement the public listing/layout, add it to navigation and change the hero’s secondary CTA to Explore Our Results. Do not publish empty case pages.
